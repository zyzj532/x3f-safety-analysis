## 数据口径（重要）

页面把材料分三级，凡非公开数据一律标注：

1. **一级 · 硬约束**：TC 受理、专用条件征求意见稿、PC 受理等规章节点。
2. **二级 · 厂商口径**：构型、冗余通道数、参数，未附失效概率与共因分析。
3. **三级 · 推定**：标注「推定」「示例」的数字，是按公开构型与标准框架推导的**量级演示**，不代表厂商设计值，也不构成对该型号适航符合性的判断。

故障树中的失效概率（如 λ=10⁻⁴/h、β=0.02）为示例假设，用于说明"冗余能否把风险压到 10⁻⁹"的量级关系，不是 X3-F 的实测数据。
